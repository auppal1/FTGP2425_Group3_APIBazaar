How API Bazaar Works

A trustless ecosystem where developers directly monetize their code, and buyers get instant, permissionless access to data.

1

Publish & Configure

Providers deploy their API endpoint URL and select a bonding curve model (Linear, Exponential) to define the pricing algorithm.

2

Mint Access Tokens

Buyers explore the marketplace and purchase API call rights using USDC. Smart contracts instantly mint access tokens to their wallets.

3

Call & Earn

Buyers hit the decentralized gateway. Tokens are burned upon successful calls, and funds are automatically unlocked for providers to withdraw.

The Advantage

Why Build on Web3?

Zero Middleman Fees

Traditional platforms take up to 30% cuts. Here, protocol fees are hardcoded at 0~5%, ensuring creators keep what they earn.

True Pay-as-you-go

No expensive monthly subscription tiers that lock buyers in. You only pay for the exact number of API calls you execute.

Anti-DDoS by Design

Economic disincentives replace rate limits. Spamming an API burns real crypto, naturally protecting providers from malicious floods.

Dynamic Discovery

Bonding curves mean early adopters get cheaper access. This incentivizes users to hunt for new, high-quality long-tail APIs early.

L2 Gas Optimization

Built on high-performance Layer 2 networks (Arbitrum, Base). Our O(1) state verification contracts ensure that interacting with the API bazaar costs pennies in gas fees, making micro-transactions for single API calls economically viable for the first time.

Frequently Asked Questions

Everything you need to know about publishing and consuming on the platform.

Do I need to rewrite my existing API?

No. You can wrap any existing standard REST or GraphQL API. You simply provide the base URL to our dashboard, and we generate a decentralized gateway proxy endpoint for your buyers to hit.

Which tokens are supported for payment?

Currently, all transactions are settled in USDC to prevent price volatility for both providers and buyers. Gas fees are paid in the native L2 token (e.g., ETH on Arbitrum).

How does the Bonding Curve protect buyers?

Buyers can "sell" unused API calls back to the curve if they over-purchased. Because the curve is deterministic, the smart contract guarantees liquidity to buy back tokens at the current curve price.
